Expenses Tracker

A simple command-line expense management application built using Python.

Features

- Add new expenses
- Update existing expenses
- Delete expenses
- View all expenses
- Input validation for expense amounts
- Interactive menu system

Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Exception handling

How to Run

1. Download the "expenses_tracker.py" file.
2. Open it using Python or Pydroid 3.
3. Run the program.

Data Storage

Currently, expenses are stored in a Python dictionary while the program is running. Expenses are not permanently saved after the program exits.
